## 🚀 Запуск и управление

```bash
python3 server.py
```

* **Для жены (Чистая игра):** `http://<ВАШ_IP>:8080`
  * До квеста видны только краткий тизер и `🔒` (без спойлеров и без доступа к DM).
  * Единый горизонтальный 3-шаговый диалог: **1. Легенда → 2. Задача, выбор Detroit и 60fps 3D-кубик d20 → 3. Вскрытие ларца с сюрпризом** (работает и при удачном, и при неудачном броске через мини-выкуп).
* **Для Мастера (DM Пульт):** `http://<ВАШ_IP>:8080?dm=master2026` (ПИН: **`2026`**)
  * **Редакция «на ходу»:** кнопка `✏️ Править` прямо на карточке точки + кнопка подстановки текущего GPS `📍`.
  * **Управление всей сессией (`🎛️ Сессия`):** отправка живых посланий на экран игрока, настройка заголовка, статов героини, радиуса GPS (`25–150м`) и свободного/последовательного порядка.
  * **Редактор точек (`📍 Локации`):** изменение названий, заданий, развилок Detroit, сложности DC, текстов при удаче/неудаче и наград с автосинхронизацией на сервер (`quests.json`).
