## 🚀 Запуск сервера

> Если у вас уже был запущен старый сервер — остановите его (`Ctrl+C`) и запустите заново, чтобы заработал новый API сохранения точек!

```bash
python3 server.py
```

* **Для жены (Чистый игровой режим):** `http://<ВАШ_IP>:8080`
  * Доступ к режиму Мастера **полностью закрыт и скрыт**.
  * Все награды скрыты за загадками (*«🔒 Секретный сюрприз»*) и открываются только после прохождения точки.
* **Для вас (Секретный режим Мастера):** `http://<ВАШ_IP>:8080?dm=master2026`
  * При открытии терминала `🗝️` запрашивается ПИН-код: **`2026`**.
  * Можно добавлять/удалять точки, тестировать демо-прогулку (`GPS Симулятор`) и скачать автономный `olha-quest.html` для хостинга на Netlify Drop / GitHub Pages.
