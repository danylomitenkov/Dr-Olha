# ⚔️ Хроники Нестведа: D&D Квест ко Дню Рождения Ольги

Интерактивный уличный веб-квест с реальной картой Нестведа (Troensevej 9), живым GPS-трекингом, кубиком d20 и системой развилок в стиле *Detroit: Become Human*.

---

## 🎁 Ваши 5 точных призов и их квесты

| Этап / Локация | Фэнтезийное имя | Реальный подарок (Приз) | Механика развилки (Detroit: Become Human) |
| :--- | :--- | :--- | :--- |
| **0. Старт в Цитадели**<br>`Troensevej 9` | Цитадель Первопроходцев | **Сумка на каждый день (Everyday Bag)**<br>*«Сумка Странника (Bag of Holding)»* | Экипируется перед выходом, чтобы складывать все найденные трофеи, бутылки и калимбу! |
| **1. Роща Диск-Гольфа**<br>`Næstved Disc Golf Bane` | Изумрудная Роща Ветров | **Калимба (Kalimba)**<br>*«Калимба Небесных Ветров»* | `[МУЗЫКА]` Сыграть 3 звонкие ноты на ветру<br>vs `[ВНИМАТЕЛЬНОСТЬ]` Найти руну у корзины |
| **2. Бастион на юге**<br>`Legeplads / Dyssegårdsvej` | Бастион Северного Мужества | **Рождественское пиво (Julebryg)**<br>*«Эликсир Храбрости»* | `[ХРАБРОСТЬ]` Сделать глоток за силу именинницы<br>vs `[ОБАЯНИЕ]` Громкий тост «Skål!» со спутником |

| **5. Финал (Дома)**<br>`Troensevej 9` | Тайный Чертог Цитадели | **Королевский Триумф**<br>*Все 5 трофеев в сборе!* | Задувание свечей, праздничный стол и 100% платиновый финал! |

## 🚀 Запуск сервера

В папке проекта запустите:
```bash
python3 server.py
```

* **Для жены (на телефон):** `http://<ВАШ_IP>:8080` (кнопка админки скрыта, только чистый геймплей).
* **Для вас (Мастер Игры):** `http://<ВАШ_IP>:8080?dm=1` (или трижды кликните по короне 👑 в обычном режиме).
