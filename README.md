# ⚔️ Хроники Нестведа: D&D Квест ко Дню Рождения Ольги

Интерактивный уличный веб-квест с анимированной средневековой картой Нестведа, живым GPS-трекингом, 60fps 3D-икосаэдром `d20`, конструктором персонажа, 3-страничным мастером квеста, контролем дистанции (Proximity Gate) и защищённым пультом Мастера игры (DM Terminal).

## 🏗️ Архитектура и Особенности

1. **Единый фронтенд без внешних сборщиков (`index.html`):**
   - Leaflet 1.9.4 для карты с кастомным пергаментным шейдером и границами `TERRA NÆSTVED`.
   - High-DPI 60fps Canvas (`#map-fx-canvas`): парусник строго по фарватеру канала Suså с кильватерным следом, стаи птиц, совы, драконы, бабочки, мерцающие духи у квестов и водная рябь от кликов.
   - 3D D20 Engine (`Dice3DEngine`): чистая математика вращения правильного икосаэдра на Canvas (кватернионы, slerp, тени, светотень, перспектива чисел и искры).
   - Конструктор персонажа (`#dialog-character`): выбор титула, аватара, цвета ауры на карте и распределение очков статов (`Харизма`, `Смекалка`, `Храбрость`).
   - Контроль дистанции (`Proximity Gate`): вдали открывается только краткое описание и маршрут; полноценный диалог с NPC, бросок кубика и вскрытие сундука открываются только на месте (или по флагу Мастера).
   - Тематические стили диалогов: каждая карточка локации окрашивается в цвета своего биома (`starlight`, `tavern`, `garden`, `darkport`, `nordic`).
2. **Бэкенд синхронизации (`server.py`):**
   - Легковесный Python HTTP-сервер на стандартной библиотеке (`http.server`).
   - REST API: `GET /api/quests` и `POST /api/quests`.
   - Живая синхронизация: правки мастера из браузера сохраняются в `quests.json` и автоматически доставляются на телефон игрока раз в 4.5 секунды.

## 🚀 Запуск и Разработка

```bash
# Клонирование репозитория
git clone git@github.com:danylomitenkov/Dr-Olha.git
cd Dr-Olha

# Запуск локального сервера
python3 server.py
# или на кастомном порту:
PORT=8080 python3 server.py
```

* **Для игрока:** `http://localhost:8080` (или `http://<IP-вашего-ПК>:8080` на телефоне в одной Wi-Fi сети).
* **Для Мастера (DM Пульт):** `http://localhost:8080?dm=master2026` (ПИН-код: **`2026`**).
  - В пульте: управление сессией, отправка живых сообщений на экран, телепортация игрока для тестов, редактор координат, текстов и наград.

## 🤝 Совместная работа через Git

- **Основная ветка:** `main`.
- **Рабочий процесс:**
  1. Перед началом правок: `git pull origin main`.
  2. Внести изменения, проверить синтаксис JS/HTML.
  3. Зафиксировать и отправить:
     ```bash
     git add .
     git commit -m "feat: описание изменений"
     git push origin main
     ```
  4. На основном устройстве: `git pull origin main` и перезапустить сервер при необходимости.
